Hemen İndirin

Windows için ücretsiz indirin ve kullanmaya başlayın

🖥️

ProjectTracker for Windows

Windows 10/11 (64-bit) • .NET 8.0 Runtime gerekli

v1.0.0
⬇️ İndir (Setup.exe)

Sistem Gereksinimleri

  • ✅ Windows 10 veya Windows 11 (64-bit)
  • ✅ .NET 8.0 Runtime
  • ✅ SQL Server (LocalDB veya Express)
  • ✅ 4 GB RAM (8 GB önerilen)
  • ✅ 500 MB disk alanı

Kurulum Adımları

Birkaç dakikada kurulumu tamamlayın

1

Gerekli Yazılımları Yükleyin

Öncelikle aşağıdaki yazılımların yüklü olduğundan emin olun:

📦 .NET 8.0 Runtime İndir 🗄️ SQL Server Express İndir
2

Uygulamayı İndirin ve Kurun

Setup dosyasını indirin ve çalıştırın. Kurulum sihirbazını takip edin.

ProjectTracker-Setup.exe
3

Veritabanını Oluşturun

SQL Server Management Studio'da yeni bir veritabanı oluşturun:

CREATE DATABASE DboProjectTracker;

💡 Uygulama ilk çalıştırmada tabloları otomatik oluşturur.

4

Bağlantı Ayarlarını Yapın

appsettings.json dosyasında veritabanı bağlantısını düzenleyin:

{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=DboProjectTracker;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
5

Uygulamayı Başlatın

Masaüstündeki kısayoldan veya Başlat menüsünden uygulamayı açın.

🎉 Tebrikler! ProjectTracker kullanıma hazır.
